# habits

Four small, self-contained web apps and a game. Each is one HTML file that runs offline in the
browser and keeps its data on the device.

| App | Where | What it does |
| --- | --- | --- |
| Daily practice | `index.html` | The habit tracker. |
| Margin | `margin/` | Notes, reminders and life admin, drawing on email, calendar invites, files and links. See [`margin/README.md`](margin/README.md). |
| Clear Read | `clear-read/` | Reads written text aloud for cochlear implant listening — one sentence at a time, with real gaps and spelled-out names. See [`clear-read/README.md`](clear-read/README.md). |
| Subtext | `subtext/` | Writes the subtitles for a video: transcribe it on the device or through a service you hold the key to, spot and tidy the cues, export `.srt` or `.vtt`. See [`subtext/README.md`](subtext/README.md). |
| Tribelands | `tribelands/` | A castaway strategy game in the spirit of Polytopia: thirteen tribes from castaway stories (Lord of the Flies, Lost, Crusoe, The Tempest…), up to eight on an island chain. See [`tribelands/README.md`](tribelands/README.md). |
