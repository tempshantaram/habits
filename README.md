# habits

Small, self-contained apps. The web ones are each a single HTML file that runs offline
in the browser and keeps its data on the device; Toss is an Android app, because what it
does cannot be done from a browser.

| App | Where | What it does |
| --- | --- | --- |
| Daily practice | `index.html` | The habit tracker. |
| Margin | `margin/` | Notes, reminders and life admin, drawing on email, calendar invites, files and links. See [`margin/README.md`](margin/README.md). |
| Clear Read | `clear-read/` | Reads written text aloud for cochlear implant listening — one sentence at a time, with real gaps and spelled-out names. See [`clear-read/README.md`](clear-read/README.md). |
| Toss | `toss/` | Sends videos from an Android phone to a Samsung TV over DLNA/UPnP, with a queue and subtitles. Android app; CI builds the APK. See [`toss/index.html`](toss/index.html). |
